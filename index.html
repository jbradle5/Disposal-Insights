How to Publish Monthly Pages on GitHub Pages

1

Enable GitHub Pages (One-Time Setup)

In your GitHub repository, go to Settings → Pages. Under Branch, select main (or master) and click Save. Your site will be published at https://yourusername.github.io/repository-name/.

2

Upload or Create the Monthly File

Save your monthly newsletter HTML file in the repository root directory with a clean filename, for example:

  • july-2026.html
  • august-2026.html
  • september-2026.html

You can add files on GitHub by clicking Add file → Upload files or Create new file directly in the web browser.

3

Link the New Page in index.html

Open index.html, add a new card to the grid, and point the link tag to your new page:

<a href="august-2026.html" class="...">Read August Edition</a>
4

Direct Access URLs

Each page is automatically live at its direct web address once committed:

https://[username].github.io/[repo-name]/july-2026.html
